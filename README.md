# StoryScene Studio

Browserbasierter Szenenbaukasten für Kamishibai-Bildkarten. Öffne die veröffentlichte GitHub-Pages-Seite und lade Hintergrundbilder und Figuren hoch. Verschieben, drehen, spiegeln, Ebenen ändern, Posen und Aussehen beschreiben, JSON importieren/exportieren und PNG-Vorschau exportieren.

## GitHub Pages
Settings → Pages → Deploy from a branch → main / (root) → Save.

**Datenschutz:** Bilder werden lokal im Browser verarbeitet. Die exportierte JSON-Datei enthält die eingebetteten Bilder und kann groß werden. Lade private Figurenbilder nicht in das öffentliche Repository hoch.
